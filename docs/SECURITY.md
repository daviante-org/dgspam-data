# Security & Artifact Verification

## Vulnerability Disclosure

Report security issues affecting `dgspamguard-data` workflows, artifact integrity, or [`daviante-org/dgspamguard`](https://github.com/daviante-org/dgspamguard) privately to **`code@daviante.org`**.

---

## Verifying Release Integrity & Provenance

Every rolling release in `daviante-org/dgspamguard-data` includes both `SHA256SUMS.txt` and cryptographic GitHub OIDC SLSA build provenance attestations generated by `.github/workflows/rolling-release.yml`:

```bash
# 1. Verify SHA-256 checksums
sha256sum --ignore-missing -c SHA256SUMS.txt

# 2. Verify cryptographic SLSA provenance attestation
gh attestation verify bundle.tar.gz --repo daviante-org/dgspamguard-data
gh attestation verify dgmail-rules.json.gz --repo daviante-org/dgspamguard-data
```
